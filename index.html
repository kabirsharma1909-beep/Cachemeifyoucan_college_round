What's inside

Pick the input that suits your day. They share the same settings.

hand_control.exe

_□×

Move a cursor with your hand through your webcam. The cursor is smoothed, and a fist click locks the target before your fingers move.

Open palm and two-finger scrolling are available, and off by default.

head_control.exe

_□×

Turn and tip your head to move your real Windows cursor across the screen. Tilt your head to scroll. Recenter whenever you drift.

Windows, primary monitor

dwell_click.cfg

_□×

Hold still to click. Partway through, the cursor locks in place, so small tremor can't move it and the click lands where you see it.

Set the hold time and how much wobble counts as still. A tick tells you when it fires.

my_signs.exe

_□×

Record your own hand sign and choose what it does: click, scroll, back or forward, open or close a tab, press a shortcut, type text, or run a voice-style command.

A sign must be released before it can fire again, so it can't repeat by accident.

Privacy

privacy.txt

_□×

Your camera frames are processed in your browser and never uploaded.

Your signs and settings are saved only in this browser.

Head control works only while it's switched on. If the page closes, it switches itself off within a few seconds.

Two things to know: the tracking models download once from public servers, and voice input uses your browser's built-in speech recognition, which in Chrome may send audio to its provider. If you add an optional Gemini key, typed or spoken commands that the built-in rules can't parse are sent to Gemini.

Set it up

About five minutes. You need a webcam.

setup.txt

_□×
  1. Install Node.js and Google Chrome. Chrome is needed for the browser window FreeHand controls.
  2. Unzip the FreeHand project, then open a terminal inside it.
    cd FreeHand
  3. Install the dependencies.
    npm install
  4. Start FreeHand.
    npm run dev
  5. Open the app, then allow camera access. You can also press Launch app on this page.
    http://localhost:5173/app.html

Optional: add GEMINI_API_KEY to a .env file to let voice commands handle open-ended requests.

Head control of the real cursor currently supports Windows only.

Questions

Does my video leave my computer?

No. Camera frames are processed in your browser and are not uploaded. The tracking models download once when you first start the camera.

Does it work on Mac or Linux?

FreeHand is built and tested on Windows. Head control of the real cursor is Windows only. The controlled Chrome window uses Playwright, so other systems may work for that part, but it isn't tested.

What if the cursor feels jittery?

Raise cursor smoothing in settings. For clicking, raise dwell steadiness so a little wobble still counts as holding still. In head mode, lower the sensitivity so small movements travel less.

Can I make my own gestures?

Yes. In my_signs, name a sign, pick an action, press Record and hold the pose through the countdown. Choose clearly different hand shapes, and use the same hand you recorded with.

How do I stop head control?

Press the Stop button, or press Esc while the FreeHand page is focused. If the page closes, control switches off within a few seconds.

Do I need a Gemini key?

No. Built-in commands like “open YouTube” or “new tab” work without one. A key only helps with open-ended requests.
